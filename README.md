A full-stack web application designed to simplify and automate school administrative and academic operations. The system provides separate role-based dashboards for Admin, Teachers, and Students to manage daily academic activities efficiently.

Key Features
Admin Dashboard: Manage students, teachers, classes, attendance, courses, exams, assignments, and school performance metrics.
Teacher Dashboard: Create and manage exams, assignments, class schedules, grading, and student performance tracking.
Student Dashboard: View schedules, access assignments, submit work, and monitor academic progress.
Secure Authentication: Role-based access control using JWT authentication.
Database Management: Efficient storage and retrieval of academic records using MongoDB.
Tech Stack

Frontend: React, Vite, styled-components
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JSON Web Tokens (JWT)
